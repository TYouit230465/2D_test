Mega Pixel Pack - Spectrum Edition
==================================

A huge pack of pixel level tiles, objects, enemies and background textures, all created to old school ZX Spectrum colour palette specifications.

With hundreds of tiles to work with, this pack provides everything you need to create a huge range of 8-bit themed levels. You can create castles, sprawling landscapes, sci-fi bases, islands, floating worlds, secret bases, ice worlds, desert pyramids, and so many more levels.

Pack includes:

- 14 different backgrounds
- 10 Special Effect animations
- 9 fully animated Enemy Sheets
- 2 example Tiled levels
- 20 Object Sheets: Doors, Coins, Traps, Fire, Liquid, Foliage, Spikes, Switches, Crates
- Hundreds of unique Level Tiles: Blocks, Bricks, Bridges, Columns, Fences, Ladders, Platforms, Special Blocks and Platforms, Terrain, Slopes

-32x32 size tiles.
-512x1024 and 512x512 backgrounds.

- Includes png format and example Tiled Map Editor project files.
- Includes animations and prefabs for all animated items.
